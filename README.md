# Lyrics Aware Smart Music Application - Frontend

A modern React-based music application that provides an intelligent lyrics-aware listening experience. Users can browse songs, view synchronized lyrics, and interact with music content through a responsive interface.

## Live Demo

https://lyrics-aware-smart-music-applicatio.vercel.app/

## Features

- User-friendly music dashboard
- Real-time lyrics display
- Responsive UI for desktop and mobile
- Song browsing and playback controls
- Dynamic API integration
- Authentication support
- Fast and optimized frontend performance

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS / Tailwind CSS
- Axios
- React Router
